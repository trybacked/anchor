# @backed/cli

Entry point: `npx backed <command>`.

| Comando | Pipeline |
|---|---|
| `init` | Crea `.backed/`, `modello.yaml` vuoto, config sorgenti |
| `model <path>` | ingest → profile → semantic |
| `review` | Apre UI review o modalità terminale |
| `diff` | Confronta run corrente vs precedente |
| `serve` | Avvia MCP server locale |
